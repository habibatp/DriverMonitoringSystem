Face landmark detection:
e modèle pré-entraîné effectue principalement trois opérations :
1. Face Detection : localiser le visage dans l'image.
2. Face Landmark Detection : identifier les 478 points caractéristiques du visage.
3. Tracking : maintenir le suivi des caractéristiques entre les images successives.

FPS signifie images par seconde.

C'est une unité qui mesure le nombre d'images qu'un système traite ou affiche chaque seconde.

Dans ton DMS, la webcam fournit une succession d'images. Pour chaque image, ton programme effectue plusieurs opérations :
1. Récupérer l'image de la webcam.
2. Préparer l'image pour MediaPipe.
3. Détecter le visage.
4. Extraire les landmarks.
5. Calculer les indicateurs.
6. Afficher le résultat.
